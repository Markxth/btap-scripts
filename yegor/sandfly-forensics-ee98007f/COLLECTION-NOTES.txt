Compatibility and limitations:
Linux/Bash only; needs Linux /proc and requests root. Enumerating process file descriptors can be slow on busy hosts. This helper does not itself capture traffic, stop processes or remove anything. Its output needs manual interpretation.

Per-file review notes:
- list-packet-sniffers/list_packet_sniffers.sh: Correlates packet-socket inodes with process file descriptors. Legitimate network tools also use packet sockets. Process exits, permissions and network namespaces can cause unmatched or missing results; an unmatched inode is not proof of a hidden process.

Integrity verification is not a security or malware-free guarantee. Review each script before use on an authorized competition host. Inspection still consumes resources and may be logged by the operating system. No system settings were changed by collecting these files.
